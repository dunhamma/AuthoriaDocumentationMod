# Authoria Almanac Stage 1 Friend Preview

This packet is a readable preview for mod friends. It is meant to answer:

- Does the Almanac help you decide what to do next?
- Does it explain what changed from vanilla Skyrim clearly enough?
- Does it warn you before you overcommit to roads, dungeons, cold, fatigue, or
  big quest hooks?
- Where did you feel confused, unconvinced, or overloaded?

## Suggested Reading Order

1. Home page.
2. Start Here.
3. Survival.
4. Regions.
5. Riverwood and Whiterun Early Hub.
6. Falkreath Hub.
7. Riften and Ivarstead Corridor.
8. Solitude Hub.
9. Windhelm Hub.
10. Winterhold Hub.
11. Markarth Hub.

## How To View

Do not double-click the HTML files. Use the local preview server so the styling
and routes load correctly.

Run this on this machine:

```powershell
PowerShell -ExecutionPolicy Bypass -File "C:\Users\Admin\Documents\Authoria - Documentation Mod\docs\share\stage1-friend-preview\preview\Start-Preview.ps1"
```

Then open:

```text
http://127.0.0.1:4173/
```

If the packet is extracted somewhere else, open PowerShell in the extracted
packet folder and run:

```powershell
PowerShell -ExecutionPolicy Bypass -File .\Start-Preview.ps1
```

## Feedback I Want

Focus on player clarity:

- What advice helped you make a decision?
- What page felt too technical?
- What warning came too late?
- What did you expect to find but could not?
- Which route or topic should be next?

## Caveats

- This is evidence-backed, not playtested.
- The region pages have local file and record evidence behind them, but exact
  route feel still needs in-game walking.
- Source notes are intentionally plain. The public guide should not read like a
  mod inventory.
- Please do not focus on full modlist completeness, record-perfect balance, or
  broad companion/quest coverage yet.
